# Thias B. Kochen — Portfolio & CV

Personal portfolio and online CV, built with Next.js (static export) and deployed to GitHub Pages.

- Portfolio: https://thias-bkh.github.io/
- CV: https://thias-bkh.github.io/cv

All content lives in `content/profile.ts`. Run locally with `npm install && npm run dev`; every push to `main` deploys.
